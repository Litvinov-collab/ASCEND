ASCEND PWA — установка

1. В GitHub-репозитории ASCEND замени текущий index.html на файл из этой папки.
2. Добавь в корень репозитория:
   - manifest.webmanifest
   - sw.js
   - папку icons
3. Оставь существующий character.png рядом с index.html.
4. Сделай Commit changes и дождись обновления GitHub Pages.
5. Открой сайт через HTTPS. В Chrome/Edge появится возможность «Установить ASCEND».

Важно:
- Supabase остаётся подключённым и работает через интернет.
- Интерфейс приложения и уже загруженные локальные файлы смогут кэшироваться.
- Для входа/синхронизации аккаунта интернет всё равно нужен.
